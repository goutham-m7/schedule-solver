## Scale curves

```sh
uv run schedule-solver benchmark --sizes 200 500 --families independent ring --budgets 0.1 10 60 --seed 7 --output artifacts/v02-final-curves
```

All inputs synthetic. [Full table](v0.2-curves.md); [metrics, objective passes/bounds, command and runtime metadata](v0.2-curves.json). All 24 generated greedy/optimized schedules were separately parsed as Workload/Result models and passed `validate_schedule()` hard-constraint checking.

At 200 people / independent / budget 60: 400 meetings, priority 794 proven optimal, 7.000s; greedy 320 meetings, priority 714, 0.668s. At 500 people / ring / budget 60: 805 versus 800 meetings, priority 1783 versus 1780, 10.762s versus 5.202s; the optimized priority was FEASIBLE with upper bound 1980, not proven optimal. All 500-person budget-0.1 and budget-10 runs used the labelled greedy fallback.

Search budgets exclude construction and greedy warm-start time. No external calendars, real users or production services were benchmarked.

## Behavior evidence

- Recurrence / DST / malformed calendars: `tests/test_recurrence.py` and `tests/test_calendars.py`, real dateutil and icalendar.
- Add/cancel/move/team stability and malformed previous assignments: `tests/test_resolve.py`, real OR-Tools and FastAPI TestClient.
- Small conflict minimum proof and honest fallback: `tests/test_minimum_conflicts.py`, independent enumeration of all smaller subsets.
- Checked export / escaping / stable UIDs / CLI / HTTP: `tests/test_export.py`, real iCalendar round trips and CLI subprocess.
- Expanded synthetic families and budget curves: `tests/test_benchmarks.py` plus the measured artifacts above.
- Native objective handoff: `tests/test_objective_handoff.py` reproduces OR-Tools returning response objective 120 while the actual assignment expression evaluates to 90. The fix reads and fixes the actual expression value.
- Package / OpenAPI metadata: `tests/test_distribution.py` and `tests/test_openapi.py`.

Real Google/Outlook UI import, hosted LLM calls, authentication and production admission control were not exercised or implemented.
